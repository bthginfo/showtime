# Vollständiger Ausbau nach dem Fachtest

Am 11. Oktober 2026 ist die Umsetzung sämtlicher Ausbaupunkte aus [ROLLEN-GEWERKE-TEST.md](ROLLEN-GEWERKE-TEST.md) freigegeben. Dieser Plan ergänzt den bisherigen Erstumfang. Die technische Umsetzung und die dokumentierten Prüfungen sind abgeschlossen; Nachweise und Grenzen stehen in [AUSBAU-ABNAHME.md](AUSBAU-ABNAHME.md).

Externe Produkte stehen noch nicht fest. Beauftragt sind eine offene versionierte API und konfigurierbare Import-/Exportwege, insbesondere CSV, mit Recherche zu marktüblichen Formaten. Arbeits-/Dienstregeln werden als bestätigungspflichtige Profile aufgebaut.

## Gemeinsame Grundlagen

- [x] Separate Rechte für Anlegen, Kommentieren, Anlagen, Antworten und Freigabe von Gewerkabstimmungen; reine KBB-Rolle nutzbar.
- [x] Rollenbezogene Startseiten und erlaubte Hauptaktionen; Gast-/Personalansicht ohne tote Aktionen.
- [x] Mobile Zeitkonto-Darstellung ohne Überlauf; verständliche Produktionsauswahl/Leerzustände.
- [x] Deutsche Fachstatus, Geldbeträge in Euro, passende theaterweite Begrüßung.
- [x] Strukturierte Referenzen für Personen, Figuren, Geräte, Räume, Fachstände und Aufgaben.
- [x] Formale Freigabe des unveränderten Fachstands mit Vier-Augen-Prüfung und nachvollziehbaren Zuständigkeiten.
- [x] Archivieren, Abbrechen, Wiederherstellen, Fassungsvergleich und nachvollziehbare Nachfolgestände.
- [x] Planungswirksame Verfügbarkeit, eingeschränkte Zeitfenster und bestätigte Regelprofile je Beschäftigtengruppe.
- [x] Produktions-/vorstellungsbezogene Bereitschaft mit begründeten Ausnahmen und geprüfter Fassung.
- [x] Fristen, Verantwortliche, Vertretung, Erinnerungen und Eskalation.
- [x] Bericht → Änderung → Aufgabe → Abnahme → Bereitschaft als verknüpfter Ablauf.
- [x] Rollenbezogene Hilfe, Übungsabläufe und geführte Einrichtung.

## Fachabläufe

- [x] Disposition: Serien-/Sammelplanung, Szenarien und Änderungsfolgen.
- [x] Regie: Szenen-/Fassungsbezug, Änderungsvergleich, verteilte Folgeaufträge.
- [x] Dramaturgie: Text-/Redaktionsstände, Lektorat, Rechtefristen und Freigaben.
- [x] Ensemble: Tageszettel, Rollen-/Aushilfenzuordnung und Verfügbarkeit.
- [x] Inspizienz: gemeinsamer versionierter Cue-Stand, Bestätigungen, Druck/Offline, Vorfälle.
- [x] Bühne: Anlagen/Dekorationen, Zeichnungen, Qualifikationen, Prüfungen und Sperren.
- [x] Licht: Gerätereferenzen, DMX-Adresskonflikte, Fokuschecklisten und Austauschformate.
- [x] Ton: Personen-/Mikrofonzuordnung, Kanal-/Frequenzkonflikte, Ersatzgeräte, Routingstände.
- [x] Video: Datei-/Cue-Bezug, technische Parameter, Fassung, Rechte und Medienablage.
- [x] Werkstätten: Stücklisten, Bestand/Bestellung, Kapazität, Schritte und geprüfte Übergabe.
- [x] Kostüm: verknüpfte Zuordnung, Maße, Anproben, Umkleidepläne und Pflege.
- [x] Maske: Besetzungs-/Perückenbezug, Pflegezyklus und Umbesetzungsfolgen.
- [x] Requisite: Verbrauch, Leihen, Rückgabe, Vorstellungschecklisten und Reparaturfolge.
- [x] Musik: Personen/Gruppen, Dienste, Aushilfen, Qualifikationen, Notenstände und Regeln.
- [x] Tanz: echte Studios/Personen, Raumeignung, Varianten und vertrauliche Verfügbarkeit.
- [x] Vorderhaus: Vorstellungsbriefing, Dienstbesetzung, Gruppenbedarf, Vorfälle und Berichtskorrekturen.
- [x] Marketing: verbindliche Freigabe, Redaktion, Assets, Rechte und Veröffentlichung.
- [x] Pädagogik: Gruppenbuchung, Räume/Personal, Kapazität, Teilnehmende und begrenzte Einwilligungsdaten.
- [x] Verwaltung: Bestellungen, Lieferungen, Rechnungsbelege, Kostenprognose und Austausch.
- [x] Haustechnik/IT: Assets, Prüf-/Wartungsserien, Zuständigkeit, Eskalation und Ressourcensperre.
- [x] Ausstattung/Bühnenbild: eigener Arbeitsbereich mit Entwürfen, Modell-/Bauprobe und Abgaben.

## Integration und Betrieb

- [x] Offene API mit dokumentierten Verträgen, scoped Zugängen, Widerruf, Limits und Wiederholschutz.
- [x] CSV/JSON-Import mit Zuordnung, Vorschau, Fehlerbericht, wiederholbarer Verarbeitung und Export.
- [x] Kalenderaustausch und Adapterprofile für Ticketing, Finanz/Lohn, CAD und Showtechnik.
- [x] Tournee-/Vertragsverwaltung und begrenzte versionierte Medienablage.
- [x] Betriebsübersicht, Verbrauch, Queue-/Datei-/Datenbankzustand, Wiederherstellung und Alarmierung.
- [x] Last-/Accessibility-/Offline-Prüfungen mit synthetischen Daten und dokumentierten Grenzen.

Prüfungen auf tatsächlich vorhandenen physischen Geräten und Interviews mit realen Beschäftigten werden getrennt von automatisierter bzw. emulierter Prüfung ausgewiesen. Sie lassen sich nicht durch eine künstliche „100 %“-Kennzahl ersetzen.
